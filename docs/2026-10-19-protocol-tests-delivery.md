本轮完成第四阶段前两步的软件实现：协议升级，以及有界自动测试和动态评价。全部开发和验证使用原生测试、模拟串口或内置演示；没有打开真实串口、接线、烧录或驱动实物。

## 已完成

| 范围 | 当前行为 |
| --- | --- |
| 协议兼容 | 固件1.3增加协议v2能力协商；旧固件继续手动控制，明确禁用不支持的自动测试。旧记录仍可回放。 |
| 会话与应答 | HELLO挑战回显、板端硬件RNG生成非零会话、递增指令序号；绑定ACK包含完整身份，查询返回板端实际通道。拒绝旧会话/重复指令，不重发运行操作。RNG失败关闭新增能力。 |
| 板端事实 | 遥测附加板端毫秒和会话，状态上报测试进度与停机原因；普通手停、遥控/反馈/心跳/USB失联、急停及测试结束均有明确原因。重连只恢复观察。 |
| 自动测试 | 单通道速度环，阶跃、斜坡、正反转；板端执行有限时长，明确零基线和尾段，完成禁用输出。显式开始才使能，不自动整定PID。 |
| 操作互斥 | 当前控制者、网页来源、反馈新鲜、全部通道停机且无其他记录才允许开始；运行中拒绝冲突修改，保留取消和全局急停。失联/接管/退出/容量耗尽会停止。 |
| 记录与评价 | 自动记录配置、单位、会话、起点、原因及样本；JSON/CSV导出，离线回放保留评价。阶跃按段计算超调%、稳定时间和稳态误差，斜坡只评价保持段稳态误差。 |

幅度限于GM6020/M3508 6000rpm、M2006 7000rpm、DM 40rad/s；基线与尾段各500–10000ms，阶段200–30000ms，总长不超过120s。正反转含500ms中间零段。已有记录容量限制继续生效：最多5条、每条60000样本/1000事件/10分钟，服务重启丢失未导出数据。

评价使用板端读取反馈时刻，所有遥测分包与当次序列目标使用同一毫秒时刻。稳定带为幅度2%（至少1rpm或0.01rad/s），持续至少200ms；稳态误差取目标减保持段末20%实测均值。起始基线及反向前零段末200ms须稳定。离线、身份/会话变化、损坏/倒退时间、间隔大于100ms、首尾不足或未完整结束会拒绝有效指标，避免把坏采样解释为电机性能。

协议完整布局和设计依据见 [设计](superpowers/specs/2026-10-19-protocol-tests-design.md)，运行和界面操作见 [上位机说明](../motor_bench_host/README.md)。
