# 一体式步进电机控制

用户选择同时实现脉冲与 RS-485。现有工作台增加“步进控制”工作区，继承现有视觉和控制权。各支持一台设备；不改变已有 CAN 电机的登记和通道协议。

## 接入方式

- 脉冲：浏览器 → 现有 Node/USB CDC → A/C 板 → PU/DR/EN。独立 TIM7 中断驱动脉冲，一次定量运动严格计数，最高 10 kHz。A 板 PA0/PA1/PA2，C 板 PE9/PE11/PE13；仅配置步进功能时接管这些 PWM 引脚。驱动器输入需匹配电平转换接口。
- RS-485：浏览器 → 同一 Node 服务 → USB-485 → 电机。实现 Modbus RTU 03/06/10、CRC16、请求应答校验、单请求队列与超时。用户图片未给厂家寄存器表；使用用户核实的寄存器配置，默认无地址，不预设其他厂家的地址。串口连接可以独立于 A/C 板运行。
- 不采用猜测厂商命令或将 RS-485 当作 CAN 的方案。RS-485 物理接口本身不能证明设备支持 Modbus；非 Modbus 设备需要对应协议适配。

## 操作与状态

脉冲包含每圈脉冲数、最高频率、EN 极性、方向反转、使能、正负转速连续运行、相对脉冲数运动、停止。每圈脉冲数为驱动器电子齿轮设置，不是编码器分辨率。报告的是已发脉冲计数、指令转速、剩余脉冲和固件输出使能状态，不宣称物理电机在线或实测速度。

RS-485 的协议配置包含启用/停用写入序列、速度写入及启动序列、相对脉冲写入及启动序列、速度/位置读取。地址、寄存器宽度、字序、缩放和控制值均由厂家手册确定。配置需提供来源和明确核实标记；不会把通信写入应答宣称为电机运动确认。连接时先停机，然后读取反馈；停止或断线后重新使能。

## 生命周期

全局急停、控制者断开、接管、心跳过期、服务关闭同时停止两种步进输出。脉冲遵循已有板端 1.5 秒心跳，并有会话和序号校验及关联应答。RS-485 在停机时使在途运动序列失效，阻止后续启动写入；通信错误后禁止继续运行，需重连。停止超时明确显示未确认。

脉冲固件能力使用协商位 16；旧固件显示升级说明。演示严格使用模拟数据，不打开物理串口。配置编辑不隐式下发或恢复运动。

## 验证

先验证协议字节、边界、分包、CRC、异站应答、超时和取消；原生 C 测试验证脉冲计数、停止、失联、方向切换及会话拒绝；A/C 固件编译；真实服务与浏览器验证演示操作、急停和窄屏。实物接线、极性和厂家寄存器需要现场验收，未获得实物验证前不宣称通过。
