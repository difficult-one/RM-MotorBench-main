# 第四阶段前两步：协议与有界测试

用户已明确要求完成协议升级、自动测试与评价；本设计落实既定优化提案，不再新增审批或提交。无接线、烧录、真实串口操作。现有暂存区及嵌套副本保留。

选择兼容扩展帧与板端执行。替换旧协议会破坏现有固件兼容；由浏览器计时发送目标不能保证页面关闭后的结束时序。保留旧指令，通过能力握手启用新增能力，板端独立运行单通道速度测试。

## 协议

保留 A5/type/len/body/CRC8/5A，负载最多64字节，LE。新固件1.3，能力版本2。

| 类型 | ID | 负载 |
| --- | --- | --- |
| HELLO | 0F | 非零主机随机挑战值u32；当前挑战重复握手幂等 |
| CAPABILITIES | 8F | version:u8、flags:u32、boardSession:u32、boardMs:u32、channelMax:u8、helloNonce:u32（回显挑战）；共18字节 |
| BIND_V2 | 10 | boardSession:u32、sequence:u32、channel/kind/bus/id/loop:u8×5 |
| BIND_ACK | 90 | session:u32、sequence:u32、result:u8、原请求绑定五字段 |
| CHANNEL_QUERY | 11 | session:u32、sequence:u32 |
| CHANNEL_REPORT | 91 | session:u32、sequence:u32、count:u8、绑定五字段×count |
| TEST_START | 12 | session:u32、sequence:u32、channel:u8、mode:u8、amplitude:f32、baselineMs:u32、phaseMs:u32、tailMs:u32 |
| TEST_CANCEL | 13 | session:u32、sequence:u32 |
| TEST_ACK | 94 | session:u32、sequence:u32、result:u8、command:u8、testId:u32、startedAt:u32 |
| BOARD_STATUS | 92 | session:u32、boardMs:u32、stopReason:u8、testState:u8、channel:u8、testId:u32、startedAt:u32、durationMs:u32 |

遥测保留原字段，在原负载尾增加 session:u32、boardMs:u32；旧解析器仍可读已有字段。读取反馈前以同一毫秒时刻更新序列，所有分包使用该时刻，避免斜坡目标与时间错位。新服务拒绝跨会话数据。板端用硬件RNG生成非零会话，检查最近8次避免近期重复；无RNG、失败或连续重复时关闭新增能力。相同当前挑战幂等，新挑战（包括重放旧挑战）先停机再生成新会话，不能复活旧START。主机只接受当前挑战回显。会话不冒充持久开机序号；重启后归零，服务清理旧事实并重新协商，绝不恢复输出。指令序号严格递增；迟到/重复指令不得重新驱动，拒绝后查询事实，不自动重试输出。旧固件不响应握手时保持手动功能，禁用新增自动测试。

## 板端测试

单通道速度环，网页来源；启动前全部通道停机，目标电机在线。启动是显式使能，不恢复历史使能。幅度正且有限，GM/M3508≤6000rpm，M2006≤7000rpm，DM≤40rad/s。baseline/tail各500–10000ms，phase 200–30000ms，整次≤120000ms。

step：零基线→幅度保持→零尾段→全停。ramp：零基线→线性升幅→同长保持→零尾段→全停。reversal：零基线→正幅保持→500ms零段→负幅保持→零尾段→全停。不自动整定PID。

完成/取消/急停/会话切换/心跳失联/反馈离线/配置改变均停止并记录原因，恢复后不续跑。所有调度依据板端毫秒时钟，无动态分配。主机额外维护控制权、命令互斥、记录容量和结果采集，不承担板端结束时序。

## 记录与评价

自动开始有界记录，完成/取消/故障时结束；保留请求配置、应答起始板端时间、会话、单位、模式和停止原因。手工记录进行中拒绝启动，避免覆盖。新增样本板端时间字段为可选项，旧记录仍兼容。

按每个恒定目标段计算相对阶跃幅度的峰值超调百分比、末20%段均值误差（目标减实测）、2%幅度误差带（至少DJI 1rpm/DM 0.01rad/s）稳定时间，持续留在误差带≥200ms。起始基线末200ms须在零误差带内；反向段前500ms零段的末200ms同样须稳定。反向段分别计算；斜坡仅评价保持段的误差，不把斜坡当阶跃。缺少基线/尾部、离线、身份变化、跨会话、板端时间倒退或>100ms间隙时明确不给有效动态指标。原始样本先检查时序，再截取测试窗，不能把损坏时间点过滤掉。网页接收时刻不替代板端取样时刻；板端时间表示测试台读取反馈时刻，不表示CAN电调内部采样时刻。

## 界面与验收

沿用现有Operate工作台；专业面板显示能力、板端停止原因；自动测试显式参数预览与开始，始终可取消/急停。记录页显示采样有效性、各目标段指标及单位。演示实现相同协议与序列，持续标模拟；实物性能仍待实机验收。

验收：协议字节/CRC/损坏输入、A/C实际C模块原生测试、板端时序与所有终止路径、真实桥接/模拟串口旧新固件互通、页面刷新/接管不续跑、浏览器完整演示与五种视口、A/C ARM构建。保留已有回归。
