# 里程碑三：记录与调试效率实施计划

依据：用户在里程碑一、二交付后要求“继续”，延续优化提案的第三里程碑。软件开发无需接线。本轮不烧录、不打开真实串口，不触 Git 索引或嵌套副本。

**Goal:** 支持可移植配置、可复用 PID、带上下文实验记录与只读分析。

**Architecture:** Vue 保持控制事实和编辑状态分离；Node 提供有界会话记录和互斥演示设备；配置、记录格式和分析算法使用可测试的浏览器安全模块。复用现有线协议、绑定和图表。

**Tech Stack:** 现有 Vue 3、TypeScript、Node、WebSocket、Canvas，无新增运行依赖。

## Global Constraints

- 配置导入先校验并预览；显式应用仅登记、解绑/绑定、配置控制来源，不保存使能/目标，不自动启动。
- 回放仅消费导入或已获取的记录，不持有命令服务；实时控制及急停仍保持可达。
- 演示与真实串口互斥，页面和导出持续标注模拟数据；演示状态切换新建会话并清除旧绑定事实。
- 记录以主机接收时间计，保留身份、控制环/单位、板端固件/会话、PID读回和操作事件。达到容量或断链自动结束，绝不停止或启动电机。
- 容量：服务最多5条记录，每条最多60000样本/1000事件/10分钟；浏览器本地最多20个场景及20个PID预设。所有导入有体积和格式上限。
