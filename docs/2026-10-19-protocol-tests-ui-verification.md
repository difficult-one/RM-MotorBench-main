# 第四阶段协议与自动测试界面验收

日期：2026-10-19。

## actual scope

本轮落实实施提案第四阶段前两步，为既有 Operate 仪器工作台的普通扩展：设备页增加协议能力和板端停机原因诊断，控制台增加板端有界自动测试，测试记录页增加动态评价。依据 `PRODUCT.md`、`DESIGN.md` 与 [协议与有界测试设计](superpowers/specs/2026-10-19-protocol-tests-design.md)；没有新视觉世界、概念稿或 seed 合同，不批准或替换既有设计系统。

核对来源：`motor_bench_host/frontend/style.css`、`bench.ts`，以及 `components/TestPanel.vue`、`TestResults.vue`、`DevicePanel.vue`、`RecordsPanel.vue`；评价有效性另核对 `motor_bench_host/test_metrics.js`。文档收尾仅写本文件，读取既有源码、系统记录、日志和截图；未重新运行浏览器、静态 detect 或硬件流程。

独立 fresh 完整 UI review 的结论为 **disposition: ship**：persistence 为 pass；TYPE、MATERIAL、GROUND、自动测试、评价真实性和工作台一致性均为 match；响应式 adaptation 符合手机要求；ceiling 为 reached；material_fixes 无。该结论只覆盖本轮普通扩展，不代表实机验收或新设计系统批准。

## persistence

沿用并保留 `PRODUCT.md`、`DESIGN.md`、`.impeccable/design.json`，未重写色板、字体、组件、断点或产品原则。专业功能继续按需展开；当前电机、实测、运行操作和持续可见的急停保持原工作台顺序。

自动测试显式展示幅度、单位、各阶段时长、总时长和目标序列；“开始测试并使能”明确表达输出后果。能力不足、绑定未确认、无控制权、非网页来源、反馈不新鲜、仍有输出或已有记录时，界面说明不能开始的原因。旧固件保留手动控制并禁用自动测试；测试完成后须等待新的停机反馈才能再次开始。运行状态与停机原因来自板端状态，不将请求已发送表达为运行成功。

测试记录沿用服务内存最近 5 条、每条最多 60000 样本 / 1000 事件 / 10 分钟和重启丢失说明；离线导入仅本页回放，服务与文件来源继续分开。名称、备注及 JSON/CSV 导出保留既有行为。

## fidelity

| 核对项 | 当前实现与既有系统的关系 |
| --- | --- |
| TYPE | 沿用本地系统中文无衬线、22px 主标题、17px 分区标题、14px 正文和 13px 标签；评价表使用等宽数字，手机表格为 12px。没有新增外部字体或展示字体。 |
| MATERIAL | 深色背景、面板、蓝色主操作、黄色状态说明和红色停机继续复用既有语义；新增分区通过色面、间距和 1px 边线组织，不增加装饰阴影。 |
| GROUND | 继续使用既有`#10151c`背景及面板色；新增表单、评价与截图底色一致，没有改变既有色温。 |
| 协议诊断 | 展示能力协商结果、板端时间和停止原因；未知时明确“待确认”。通道清单刷新受实际能力和控制权约束，不将本地请求作为板端事实。 |
| 自动测试 | 通过折叠区加入当前速度环；阶跃、斜坡、正反转均有参数预览与有界序列说明。运行时锁定参数，保留取消测试并停机及全局急停。 |
| 评价真实性 | 评价使用板端读取反馈时刻；展示单位、稳定带、至少 200ms 和末 20% 段均值误差定义。斜坡只评价保持段误差，不适用的指标显示“未达到/不适用”。 |
| 无效指标 | 未完整完成、采样首尾不足、离线、身份/控制环变化、跨会话、时间倒退/重复或超过 100ms 间隙，以及零基线未稳定时，显示无法给出有效动态指标及具体原因。原始时间检查先于测试窗截取。 |
| 工作台一致性 | 目标草稿、实测和板端状态继续分开；记录回放只读，PID 按需展开；自动测试没有改变既有基础操作入口。模拟来源在顶栏、记录列表和回放中持续标识。 |
| 响应式与安全入口 | 保留 1600 / 1150 / 760px 断点；手机测试参数改为两列、操作分行，结果表允许单元格换行。五种结果视口无横向溢出、急停可见；手机配置截图保留使能与停止入口。 |
| 控件状态 | 复用主要按钮和输入至少 40px 高、轻圆角、2px 蓝色可见焦点与 160ms 状态变化；减少动态效果设置继续生效。 |

## ceiling

本轮仍以任务、数值、板端事实和明确操作为表达上限。协议诊断、折叠测试参数和评价表服务于调试，复用既有平面工作台和信息层级，没有引入新的视觉身份。独立完整 UI review 判定 ceiling reached，未提出需要追加的 material fixes。

## material_fixes

独立完整 UI review 未提出 material fixes。本轮静态 detect 仅执行一次，结果为 `[]`，文档收尾未重复执行。

主线程已确认末次 `npm run check` 以 exit 0 完成；日志为 `output/playwright/protocol-tests-check.log`，包含 lint、类型检查、构建、已有回归及新增 11 项协议 / 序列 / 指标 / 演示时钟测试和 V2 服务验证。A/C 新旧原生回归及 ARM 构建均通过，包括普通手停、反馈丢失和遥控失联原因增量。

主线程浏览器回归使用生产构建和内置演示完成开始 → 取消 → 再开始 → 自动完成 → 自动记录 → JSON 导出 / 导入 → 有效评价，pageerror 为 0；旧固件能力禁用自动测试、原工作台、反馈过期和第三阶段分析回归通过。此处记录主线程已完成的结果，不扩大为真实电机验证。完整软件交付范围见 [交付记录](2026-10-19-protocol-tests-delivery.md)。
