## 已交付

- Vue 3 + TypeScript + Vite 工作台：固定顶栏、控制台、设备诊断、选中通道控制、有界 Canvas 波形、可展开 PID。支持桌面、平板及 390px 手机。
- 连接引导；登记后的板端清单；按身份选择电机及控制环；目标草稿、服务发送结果、板端当前目标分别显示；备注按身份保存。
- PID 默认值/本地编辑/最近板端读回分列；读回不覆盖草稿；旧 `motor-bench:pid:v1` 按身份与环迁移为 v2；损坏回退并提示。DM 当前固件不支持运行期 PID 写入/读回，界面明确标注。
- 服务统一校验类型、通道、型号、总线、ID、已知 CAN 反馈冲突、控制环、目标范围及 PID 编码范围。共享定义不依赖 Node Buffer。
- WebSocket 退避重连、状态快照；控制者/观察者与主动接管；控制者断开或租约到期全停；观察者退出不影响运行。
- 请求 ID 关联浏览器与服务；板端已有 ACK 对应的操作单独等待；超时提示结果未确认，隔离同类重试直到新串口会话，避免迟到应答覆盖新操作。
- 串口打开/关闭串行；新会话清理解析器、遥测、绑定和待办；打开即全停；连续目标按通道合并，停机清除尚未发出的目标；观察和重连不重放运行指令。
- 服务最近 100 条连接/操作事件。完整实验记录、CSV、回放仍属下一里程碑。
- A/C DM 驱动：只有实际 CAN 解码回调建立在线状态；500ms 反馈超时清目标、停机，恢复反馈只恢复在线，必须显式重新使能。

## 协议及验收边界

当前 USB 线协议没有请求序号、绑定 ACK、绑定清单及板端会话 ID。浏览器请求 ID 只在服务层生效；绑定仍沿用“已知空闲通道的下发 + 后续遥测”规则，不把任意首帧猜成绑定成功。已有未知通道只能显式识别显示，运行前需明确解绑并重绑。控制来源成功反馈按来源、限幅和轮序匹配；底盘使能以遥测为准，单独的 CONTROL_REPORT 不证明使能成功。

软件急停区分已请求、已知通道禁用反馈与失联未确认。它不能证明未知通道、物理供电或轴系已安全停止。

本轮未连接真实串口、驱动电机或烧录。DM 500ms 反馈门限、实际安装方向、USB/遥控器/电机反馈失联及 8 通道连续 30 分钟性能，仍需在目标电脑和 A/C 实物上验收。未实施自动 PID 整定、自动测试序列、能力协商及绑定协议扩展。
